# 白天主题与工作区视觉改版

日期：2026-10-10。设计方向：**暖白工作台**。优先支持长时间阅读、连续对话和多面板工作。

## 现状评审

| 现状 | 使用影响 | 本次调整 |
| --- | --- | --- |
| 白天主题以相近的中性灰铺满背景、导航和选中态 | 内容、工具和当前位置的层级较弱 | 纸白内容区、暖灰侧栏、白色输入区；松绿只强调操作与选中态 |
| 全局导航只显示图标 | 切换聊天、项目、架构依赖悬停识别 | 常驻短标签，保留完整 Tooltip 和无障碍名称 |
| 项目页直接进入搜索和密集列表 | 缺少页面标题与明确的主操作 | 标题、说明、打开项目按钮、最近项目列表分层排列 |
| 会话标题与相对时间挤在同一行 | 常用宽度下，短标题也频繁截断 | 标题与时间双行，完整标题可悬停查看 |
| 分类入口说明偏实现细节，欢迎元素层级不统一 | 开始新任务前需要理解过多术语 | 共用欢迎标题组件，精简说明，保留分类与示例操作 |
| 外观选项只有三个文字按钮 | 切换前无法判断主题效果 | 晴昼、静夜、跟随系统三张预览卡；支持原生单选键盘操作 |

## 案例借鉴

- **Cursor：以 Agent 与任务为中心。** 官方介绍强调围绕 Agent 组织工作区，并保留随时深入文件与变更的路径。本项目继续保留会话、文件、变更与工作流的既有结构，用较安静的导航背景和明确的选中态降低视觉竞争。[Cursor 2.0 官方介绍](https://cursor.com/blog/2-0)
- **Claude：对话与产物各有空间。** 官方 Artifacts 说明展示了对话旁的独立产物区域。本项目保留详情、浏览器、文件与工作流面板，把对话正文和输入框约束在可读的居中列中。[Claude Artifacts 官方说明](https://claude.com/resources/articles/build-artifacts)

以上借鉴的是信息组织方式；暖白、松绿与中文排版是针对本项目的设计选择。

## 视觉规范

| 角色 | 晴昼 | 静夜 |
| --- | --- | --- |
| 阅读背景 | `#fcfbf8` | `#19211d` |
| 导航背景 | `#f1f2ec` | `#171e1a` |
| 主文字 | `#242a27` | `#e5eae4` |
| 辅助文字 | `#616c63` | `#a4b2a6` |
| 操作强调 | `#246453` | `#9ccdb5` |

- 颜色权威仍在 `src/App.css`；明暗主题与 RGB 伴随令牌同步维护。
- 使用现有字体栈：Avenir Next、思源黑体／苹方等中文回退；代码保留 JetBrains Mono。
- 阅读正文保持 15px，欢迎标题 24–32px，侧栏标题 13px，时间等次要信息 11px；正文与输入框最大宽度仍为 760px。
- 输入区采用轻阴影；普通卡片使用细边框；避免整屏堆叠强阴影或装饰渐变。
- 导航宽 68px，提供图标与文字；项目列表有独立的名称、路径、时间、打开入口。分屏空间预算同步为 68px，并覆盖 1304px／1303px 的临界窗口测试。
- 分类与示例网格按聊天容器宽度切换列数，适用于分栏工作区；项目页与主题卡片在窄窗口收敛。
- 成功、警告、错误、信息各保留语义色；运行状态继续使用文字与图标共同表达。
- 为键盘焦点、文字选区和减少动态效果提供统一处理；Git diff 使用同源语义令牌。

## 可读性核验

按 sRGB 相对亮度计算的代表性对比度：

| 组合 | 对比度 |
| --- | --- |
| 晴昼正文／阅读背景 | 14.14:1 |
| 晴昼辅助文字／阅读背景 | 5.29:1 |
| 晴昼辅助文字／侧栏 | 4.87:1 |
| 晴昼主按钮文字／按钮背景 | 6.95:1 |
| 静夜正文／阅读背景 | 13.49:1 |
| 静夜主按钮文字／按钮背景 | 8.51:1 |

核心文字与七类表面的组合最低为晴昼 4.57:1、静夜 4.56:1。这是令牌级核验，不等同于对全部运行期内容的无障碍认证。

- `pnpm test`：69 个文件、668 个测试通过。

- `pnpm build` 通过；已有大型 vendor chunk 体积提示仍存在。
- 使用隔离 Chromium 与虚构数据加载真实 React 应用。Tauri IPC 全部模拟，未知命令明确拒绝；视觉验证不访问用户数据库、不调用模型服务。
- 已检查 1440px 首页、项目列表、明暗外观设置，以及消息中的长文、引用、工具状态、代码块和表格。
- 900px 普通与减少动态效果模式下，分类卡片均可见且可点击；主题点击、方向键切换与模拟保存成功。控制台错误、页面错误及未知 IPC 均为零。

本次未启动完整 Tauri 应用；原生窗口、真实 IPC、项目详情／工作流面板、终端进程和 Agent 执行链路不属于本次浏览器验收结果。
