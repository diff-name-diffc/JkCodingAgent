## 最重要的判断

- **空间与层级优先于皮肤。** 多栏工作区的聊天列宽、编辑器、文件树、详情栏缺少统一分配策略；执行图还出现被文件栏遮挡的实际问题。
- **保留好的基础。** 现有主题令牌、Radix 基础组件、折叠工具轨迹、输入框、图编排和代码预览值得继续复用。
- **减少视觉负担。** 收敛侧栏大阴影、渐变、青绿色描边、大圆角及重复标题；让状态色、主要行动和代码差异成为视觉重点。
- **统一工作台，不统一所有数据。** 普通聊天、项目会话、架构画布共用视觉骨架，各自保留作用域与生命周期；架构设计图与运行 DAG 仍是两种对象。
- **把完成任务的路径做顺。** 发起 → 观察执行 → 查看产物/差异 → 验证 → 用户决定提交；日志、模型设置和工具配置按需展开。
