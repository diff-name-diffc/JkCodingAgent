# 白天/暗夜主题修复实现计划

## 问题诊断

主题切换的逻辑链是正确的（`ui-store.ts` 的 `setTheme` → `html.dark` class toggle → App.css 变量切换），但 **light 模式永远显示暗色**，根因有二：

1. **4 个 shell scope 类硬编码覆盖了 design tokens**：`.ai-shell`(L20)、`.ai-home-shell`(L612)、`.ai-project-shell`(L1227)、`.ai-chat-shell`(L8401) 直接把 `--text-primary`、`--accent`、`--bg-*` 等钉死为暗色值，没有 `html.dark` 守卫。
2. **~800 个 `.ai-*` 子组件类内联了 ~900 行硬编码暗色 `rgba()`**（如 `rgba(5,14,26,0.72)`），而非引用 token。另有 162 处 `!important` 锁死暗色。

结果：即使 `html.dark` 不存在，`:root` 的 light token 也被 shell scope 覆盖，且子组件直接用暗色字面量。

## 设计方向：清爽舒适的 light 配色

**light 模式不走科幻青绿暗色调**，而是清爽舒适的浅色系：
- 背景：温润的米白/雾白渐变（非纯白），带极淡的青色辉光点缀
- 文字：深炭灰主文字 + 中灰次文字（高对比、不刺眼）
- accent：科幻青在 light 下降饱和为深青 `#0d9488`（App.css 已有）
- 面板/卡片：纯白 + 极淡阴影，边框用浅青透明色
- 网格纹理：极淡的青灰线条（几乎不可见），保留质感但不喧宾夺主

## 实现方案

### Step 1: 在 App.css 中新增科幻语义 token（light + dark 双值）

在 `:root`（light）和 `html.dark` 中各新增一组 `--sf-*`（sci-fi）语义变量，把 tailwind.css 里散落的硬编码值收口为 ~15 个 token：

```css
/* light（清爽舒适） */
:root {
  --sf-shell-bg: linear-gradient(135deg, #f4f7f5 0%, #eef2ed 50%, #f0f5f3 100%);
  --sf-shell-glow-1: rgba(13, 148, 136, 0.06);  /* 极淡青辉光 */
  --sf-shell-glow-2: rgba(234, 179, 8, 0.04);   /* 极淡暖辉光 */
  --sf-surface: rgba(255, 255, 255, 0.88);       /* 面板/卡片 */
  --sf-surface-elevated: rgba(255, 255, 255, 0.96);
  --sf-surface-sunken: rgba(244, 248, 246, 0.8); /* 凹陷行/输入框 */
  --sf-overlay: rgba(15, 26, 30, 0.32);          /* 对话框遮罩 */
  --sf-accent-border: rgba(13, 148, 136, 0.22);  /* 青色边框 */
  --sf-accent-border-strong: rgba(13, 148, 136, 0.42);
  --sf-accent-glow: rgba(13, 148, 136, 0.1);     /* hover/选中辉光 */
  --sf-grid-line: rgba(13, 148, 136, 0.04);      /* 网格纹理线 */
  --sf-grid-mask-opacity: 0.35;
  --sf-shadow-panel: 0 4px 16px rgba(15, 26, 30, 0.06);
  --sf-shadow-elevated: 0 12px 40px rgba(15, 26, 30, 0.1);
}

/* dark（保持现有科幻暗色） */
html.dark {
  --sf-shell-bg: linear-gradient(135deg, #050711 0%, #091525 48%, #03050b 100%);
  --sf-shell-glow-1: rgba(33, 244, 223, 0.18);
  --sf-shell-glow-2: rgba(255, 189, 90, 0.12);
  --sf-surface: rgba(8, 18, 31, 0.84);
  --sf-surface-elevated: rgba(13, 28, 47, 0.94);
  --sf-surface-sunken: rgba(3, 9, 17, 0.78);
  --sf-overlay: rgba(0, 0, 0, 0.58);
  --sf-accent-border: rgba(94, 242, 234, 0.16);
  --sf-accent-border-strong: rgba(94, 242, 234, 0.38);
  --sf-accent-glow: rgba(33, 244, 223, 0.12);
  --sf-grid-line: rgba(79, 228, 221, 0.055);
  --sf-grid-mask-opacity: 0.7;
  --sf-shadow-panel: 0 20px 60px rgba(0, 0, 0, 0.26);
  --sf-shadow-elevated: 0 30px 90px rgba(0, 0, 0, 0.48);
}
```

### Step 2: 把 4 个 shell scope 的 token 覆盖改为 `html.dark` 守卫

- `.ai-shell` → 拆为 `.ai-shell`（仅 layout，不含 token 覆盖和暗色背景）+ `html.dark .ai-shell`（暗色 token 覆盖 + 暗色背景）
- light 模式下 shell 直接用 `:root` 的 token + `var(--sf-shell-bg)` 背景
- `.ai-chat-shell` 的 ~40 个 markdown/chat token 覆盖同理移入 `html.dark .ai-chat-shell`

### Step 3: 批量替换 tailwind.css 中的硬编码色值为 `var(--sf-*)`

按分类映射：
| 硬编码模式 | 替换为 |
|---|---|
| `rgba(5,14,26,*)` / `rgba(8,18,32,*)` / `rgba(7,16,28,*)` 等深色面板 | `var(--sf-surface)` |
| `rgba(3,8,16,*)` / `rgba(4,9,18,*)` 等更深的凹陷面 | `var(--sf-surface-sunken)` |
| `rgba(8,18,32,0.98)` 等高不透明对话/浮层 | `var(--sf-surface-elevated)` |
| `rgba(94,242,234,0.1x)` 青色边框 | `var(--sf-accent-border)` |
| `rgba(94,242,234,0.3x)` 强青色边框 | `var(--sf-accent-border-strong)` |
| `rgba(33,244,223,0.1x)` 青色辉光/hover | `var(--sf-accent-glow)` |
| `rgba(79,228,221,0.05)` 网格线 | `var(--sf-grid-line)` |
| `rgba(0,0,0,0.4x)` 对话框遮罩 | `var(--sf-overlay)` |
| `rgba(0,0,0,0.2x)` 面板阴影 | `var(--sf-shadow-panel)` |
| `rgba(255,255,255,0.03~0.05)` inset 高光 | light 下移除/弱化（用 token） |

同时移除不必要的 `!important`（大部分是为覆盖 shell scope 的优先级，token 化后不再需要）。

### Step 4: 调整 `.ai-shell::before` / `.ai-chat-shell::before` 等网格纹理

- 网格线颜色改用 `var(--sf-grid-line)`
- `opacity` 改用 `var(--sf-grid-mask-opacity)`（light 下几乎不可见）

### Step 5: 验证

- `pnpm exec tsc --noEmit` + `pnpm lint` + `pnpm build` 通过
- 浏览器烟测：Home / Project / Chat 三个 shell 在 light 和 dark 下均正常
- 确认切换主题时无闪烁、无残留暗色

## 影响范围

| 文件 | 改动 |
|---|---|
| `src/App.css` | 新增 `--sf-*` token（light + dark 各 ~15 个变量） |
| `src/styles/tailwind.css` | shell scope 拆分 `html.dark` 守卫 + 批量替换硬编码色值为 `var(--sf-*)` + 移除多余 `!important` |

不改动任何 TSX 组件、store 逻辑、tailwind.config.js。纯 CSS 层修复。
