## 2. 阴影与材质（定稿）

- 常驻栏（rail/导航/工具条/状态条）：**无外阴影**；分区靠表面明度差 + 1px `--border-dim`。
- popover：`--shadow-sm` 轻阴影；modal：`--shadow-md`；详情覆盖层（embedded Artifact）：`--shadow-lg`。
- 输入框单层浅阴影；工具行、Markdown 代码块、编辑器**不发光**；移除 `--sf-accent-glow`/`--shadow-accent-glow` 的常驻使用（仅保留焦点环 `--shadow-focus`）。

## 3. 排版（定稿，02-design §4.2 全采纳）

| 元素 | 规格 |
|---|---|
| UI 主字体 | 系统 UI + PingFang SC / Noto Sans SC（验证现有 `--font-ui` 优先级后收敛） |
| 主界面文字 | 13px/20px，400；重要项 500–600（去除 750/850 权重） |
| 聊天正文 | 15px/24px |
| 代码/终端 | JetBrains Mono 13px/20px（保留 `--font-mono` 回退栈） |
| 辅助信息 | 12px/18px（路径/时间/用量；核心操作不低于 12px） |
| 页面标题 / 工作区标题 | 18px/26px / 14px/20px |
| 行高 | 文件树 28px、会话行 40–48px、工具行 32px |
| 间距 | 4/8/12/16/24/32 |
| 圆角 | 按钮 6、行/菜单 8、卡片/输入 12、modal 16；工作区与编辑面 0–4（移除编辑器 24px） |
| 图标 | lucide 16 常规 / 18 导航；图标按钮 32×32，紧凑 ≥24×24 |

对比度门槛：正文 ≥4.5:1、大文字 ≥3:1（WCAG 2.2）；实测走查在 UI-29 执行，本表数值为设计承诺而非实测结论。

## 4. 动效（保留现状节奏）

hover 120ms、抽屉/折叠 180ms（`--motion-fast/normal`）；拖动实时跟手无弹簧；消息流不逐 token 入场动画；尊重 reduced-motion；主题切换不追加大面积过渡（现状 `.dark` 直切保留）。

## 5. 视觉评审结论（进入 UI-06 的硬门禁记录）

1. 关键帧六场景的全部视觉入口均对应现有能力或已登记后续任务（执行图标签=UI-13、Git 提交区=UI-17、助手上下文=UI-15），无凭空入口。
2. 表面提亮（`--bg-panel` 浅色改纯白）会放大 Monaco/Shiki/xterm 自带主题的反差——UI-06 阶段 B 按域换肤时第三方渲染器选择器列为红线不碰，反差问题留 UI-29 实测。
3. 深色导航 `#111413` 比画布 `#151817` 更暗（反向明度差），与浅色方向相反属有意设计（石墨槽感）；如 UI-29 实测混淆再回调。
4. 状态色一律双编码（图标+文字），keyframes.html 中以 pill 文案示范；只靠彩点的现存实现（会话行 spinner 除外）在 UI-12/22 收敛。
