## 通用纪律（每阶段遵守）

- schema 变更 = SCHEMA_VERSION 递增 + 基线 DDL 同步 + 迁移事务（数据导入在事务内、文件清理在 commit 后 best-effort，照 v30 形态）+ 升级回归测试。
- `types.ts` 与 Rust 结构体同步修改；命令 `invoke<T>()` 带泛型。
- 重 I/O 命令 spawn_blocking；持锁期间不做 I/O。
- 每阶段独立交付：`cargo test` + `pnpm build` + `pnpm lint` 全绿后进入下一阶段；手动冒烟（pnpm tauri dev）覆盖对应设置页。
- 不提交 git（工作区已有大量未提交改动，除非用户要求）。
